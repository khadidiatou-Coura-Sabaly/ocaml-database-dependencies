# OCaml Database Dependencies

A functional programming project in OCaml focused on relational databases, functional dependencies, candidate keys, and database normalization.

## Overview

This project implements several operations related to the relational database model. It explores how functional dependencies can be used to determine candidate keys and study database normal forms.

## Features

- Relational database operations
- Representation and manipulation of functional dependencies
- Candidate key computation
- Database normalization
- Tests for database operations and functional dependencies

## Technologies

- **Language:** OCaml
- **Tools:** OCaml compiler (`ocamlc`), Make
- **Concepts:** Functional programming, relational databases, functional dependencies, candidate keys, normalization

## Getting Started

### Prerequisites

- OCaml
- Make

### Build the project

Clone the repository and enter the project directory:

```bash
git clone https://github.com/khadidiatou-Coura-Sabaly/ocaml-database-dependencies.git
cd ocaml-database-dependencies
```

Compile the project:

```bash
make
```

### Run

If the build produces the `test` executable, run:

```bash
./test
```

To remove generated files:

```bash
make clean
```
